# LC 工具箱

两个自用 Android 应用的分发与更新仓库。

---

## 应用

| 应用 | 包名 | 说明 |
| --- | --- | --- |
| **LC工具** | `lc.hook.nb` | 设备辅助工具箱 |
| **凉菜管家** | `com.liangcai.manager` | 手机端 QQ 机器人管理 |

---

### LC工具

运行在已获取 root 权限设备上的辅助工具箱：

- 模式切换与运行状态提示
- 卡图 / 名片 / 普通图多套路径独立配置
- 悬浮窗显示，宽度与透明度可调
- 实况通知常驻（兼容 OPPO 流体云、vivo 原子岛）
- 液态玻璃底部导航，多套主题可选

### 凉菜管家

在手机上直接部署和托管 QQ 机器人的管理端，内置 proot 运行环境，不需要电脑和云服务器：

- 一键部署 / 启动 / 重启 / 停止
- AI 闲聊、关键词回复、入群欢迎
- 群聊 @ 回复、图片识图
- 消息日志、崩溃日志、图片日志
- 一键打包全部日志、清空部署环境

## 更新检测

两个应用启动时都会静默读取本仓库根目录下的 JSON 清单，与本地版本号比较后决定是否提示。

| 应用 | 清单文件 |
| --- | --- |
| LC工具 | [`version.json`](version.json) |
| 凉菜管家 | [`lcmanager.json`](lcmanager.json) |

清单格式：

```json
{
  "versionCode": 26,
  "versionName": "2026.10.27",
  "minVersionCode": 0,
  "changelog": "1. 修复若干问题\n2. 优化启动速度",
  "downloadUrl": "https://github.com/licn07/lc-/releases/download/v26/app.apk",
  "size": 35483927,
  "md5": ""
}
```

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `versionCode` | 是 | 整数。只有大于安装包内的 `versionCode` 才会提示更新 |
| `versionName` | 是 | 展示用版本号 |
| `minVersionCode` | 否 | 低于此版本强制更新，不提供「稍后」；`0` 或省略表示不强制 |
| `changelog` | 否 | 更新日志，弹窗内展示 |
| `downloadUrl` | 是 | APK 直链，建议使用 Release 附件地址 |
| `size` | 否 | 字节数，仅用于在弹窗内展示安装包体积 |
| `md5` | 否 | 预留字段 |

两个应用各有独立清单，**不要合并成一个文件** —— 版本号序列不同，混用会互相误判。
