# 凉菜管家

在手机上运行 QQ 机器人的管理端，不需要电脑、不需要云服务器。

内置 proot 运行环境，装好 APP 就能直接部署机器人本体，配置、启停、日志全部在手机上完成。

---

## 功能

### 部署与运行

- 首次打开自动解压内置运行时，一键完成部署
- 启动 / 停止 / 重启，实时显示进程状态
- 后台守护服务：APP 被杀、手机重启后可自动恢复
- 期望状态持久化，开机不需要重新点启动
- 清空部署环境：测试时一键回到干净状态（保留登录凭证）

### AI 闲聊

- 兼容 OpenAI 格式的任意 API：Base URL、API Key、model 三项自己填
- 人设（System Prompt）可自定义
- 识图回复：群里发的图片能看图作答
- 图+文消息自动合并，避免同一件事回两遍
- @ 回复者开关
- 群聊非 @ 消息可单独开启（默认只回 @）
- 联网搜索开关

### 关键词回复

- 多组关键词规则，逗号分隔，命中即回
- 每条规则的回复文案独立编辑
- 白名单机制

### 入群行为

- 新成员入群欢迎
- 欢迎语自己随意改
- 主动消息受限时自动入队，等下一条群消息借 msg_id 补发

### 记忆库

- 群内对话历史可检索
- 支持查看与整理

### 日志与排查

- 消息日志：机器人收发记录，按群、按关键字过滤
- 图片日志：识图通道独立记录
- 崩溃日志：异常自动捕获并落地
- 一键打包全部日志为 zip
- 同步脚本：对比 APP 内置脚本与运行中版本的 md5

### 外观

- 液态玻璃界面，透明度可调
- 五套主题：咖啡 / 抹茶 / 海洋 / 莓果 / 墨
- 自定义背景图
- 深色 / 浅色跟随系统

## 使用前

需要 root 权限。机器人本体跑在 proot 环境里，启停、读日志、写配置文件都走 root 通道。

设备没有 root 的话，装上也跑不起来。

---

## 安装

适用于 Android 11（API 30）及以上。

从 [Releases](../../releases/latest) 下载最新 APK 直接安装。

所有版本为同一签名，可以直接覆盖升级，应用内数据（配置、凭证、日志）会保留。若签名不一致，需先卸载旧版，数据会丢失。

---

## 首次配置

1. 打开 APP，等待运行时解压完成
2. 进「设置」页填写机器人账号与登录凭证
3. 进「AI」页填 API 端点、密钥、模型
4. 回首页点「启动机器人」
5. 日志出现上线提示即成功

---

## 更新

APP 启动时会在后台静默检查新版本，有新版本时弹窗提示。

更新清单读取本仓库根目录的 [`lcmanager.json`](lcmanager.json)，只读静态文件，不上报任何数据。

---

## 已知限制

- 欢迎语等主动消息需要机器人所在群开通主动发言权限，否则会被平台拒绝，转入队列等待借群消息补发
- 补发只能在**同一个群**触发，不会跨群窜发（刻意设计，避免把 A 群的欢迎语发进 B 群）
- proot 环境在部分机型上可能被杀后台，建议给 APP 加电池白名单
